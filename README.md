# Demo · Ver en mi oficina con la cámara

Ficha de producto simulada de FactoryOficina con el botón «Ver en mi oficina con la cámara»:
el mueble a su medida real sobre la cámara del móvil (realidad aumentada en Android e iPhone).

Abrir en el móvil: https://filmbyatlas.github.io/demo-camara-factoryoficina/

Generada con `npm run demo-camara` en el repositorio INTEGRAR-MUEBLES. Solo es una demo: el carrito es simulado.
